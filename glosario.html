Norma IEEE · WLAN

IEEE 802.11

Familia de estándares para redes locales inalámbricas. Es la base técnica de Wi-Fi; sus enmiendas incluyen 802.11n, 802.11ac, 802.11ax y 802.11be.

Norma IEEE · WLAN

IEEE 802.11a/b/g/n

Enmiendas de distintas generaciones de Wi-Fi. 802.11b y g usan 2.4 GHz; 802.11a usa 5 GHz; 802.11n puede operar en 2.4 y 5 GHz. Las capacidades dependen del equipo y la configuración.

Norma IEEE · Ethernet

IEEE 802.3

Familia de estándares de Ethernet, la tecnología de redes de área local cableadas. Complementa a Wi-Fi, pero no es un estándar inalámbrico.

Norma IEEE · Acceso

IEEE 802.1X

Método de control de acceso a una red mediante autenticación de dispositivos o usuarios. Se usa en redes empresariales cableadas e inalámbricas; no es un método de cifrado por sí solo.

Norma IEEE · Histórica

IEEE 802.9

Proyecto histórico de la familia 802 para redes LAN integradas de voz y datos. No corresponde a Wi-Fi ni es la norma actual para redes inalámbricas.

Norma IEEE · Acceso inalámbrico de banda ancha

IEEE 802.16

Familia de estándares para acceso inalámbrico de banda ancha en áreas metropolitanas, asociada históricamente con WiMAX. No es Wi-Fi (802.11), aunque ambas transmiten datos sin cables.

Norma IEEE · Redes personales

IEEE 802.15

Familia de estándares para redes inalámbricas de área personal (WPAN), pensadas para comunicaciones de corto alcance. Es distinta de las WLAN de 802.11.

Generación Wi-Fi

Wi-Fi 4, 5, 6, 6E y 7

Nombres de generaciones asociadas, respectivamente, con 802.11n, 802.11ac, 802.11ax y 802.11be. Wi-Fi 6E extiende Wi-Fi 6 a la banda de 6 GHz donde esté permitida.

Concepto de red

Wi-Fi

Nombre de una tecnología y marca de certificación para productos basados en IEEE 802.11. No es sinónimo de Internet: permite conectar dispositivos a una red local que puede tener salida a Internet.

Concepto de red

WLAN

Red de área local inalámbrica (Wireless Local Area Network). Conecta dispositivos en un espacio limitado usando tecnologías de radio como Wi-Fi.

Equipo

Punto de acceso (AP)

Equipo o función que permite a los dispositivos Wi-Fi unirse a una red local y puentea el tráfico inalámbrico con la red cableada.

Equipo

Router

Dispositivo que dirige tráfico entre redes. En hogares suele integrar router, punto de acceso Wi-Fi, switch y, a veces, módem.

Concepto de red

Hotspot

Zona donde se ofrece conexión Wi-Fi. Puede ser privada o pública, abierta o protegida con contraseña y portal de acceso.

Configuración

SSID

Nombre que identifica una red Wi-Fi en la lista de redes disponibles. Ocultarlo no reemplaza el cifrado ni vuelve segura una red.

Radio

Banda y frecuencia

Wi-Fi utiliza bandas como 2.4, 5 y, en equipos compatibles, 6 GHz. Cada banda tiene características distintas de alcance, capacidad y disponibilidad regional.

Radio

Canal

Porción de una banda de radio que usa una red. Elegir canales adecuados puede reducir la interferencia de redes cercanas; la selección automática del router suele ser suficiente en casa.

Tecnología

MIMO

Técnica que usa varias antenas para transmitir y recibir datos. Puede mejorar capacidad y rendimiento cuando tanto el punto de acceso como el dispositivo la admiten.

Arquitectura

Red mesh

Sistema con varios nodos que cooperan para ampliar cobertura Wi-Fi. Los nodos se enlazan entre sí y presentan una red coordinada a los dispositivos.

Medición

Mbps

Megabits por segundo, unidad de tasa de transferencia de datos. No debe confundirse con MB/s (megabytes por segundo): un byte equivale a ocho bits.

Medición

Latencia

Tiempo que tarda un dato en ir de un punto a otro, normalmente medido en milisegundos. Una conexión rápida puede tener latencia alta y viceversa.

Seguridad · Obsoleto

WEP

Protocolo antiguo de seguridad para Wi-Fi. Sus debilidades permiten vulnerarlo con facilidad; no debe utilizarse.

Seguridad · Evitar

WPA y TKIP

WPA fue una solución transitoria y TKIP su mecanismo de protección. Ambos se consideran obsoletos para redes actuales y deben evitarse.

Seguridad · Recomendado

WPA2, AES y CCMP

WPA2 con AES/CCMP sigue siendo una opción segura cuando WPA3 no está disponible. Conviene evitar el modo mixto que habilita TKIP.

Seguridad · Recomendado

WPA3

Generación más reciente de seguridad Wi-Fi para redes domésticas y personales. Se recomienda cuando es compatible con el router y los dispositivos.

Seguridad

Firewall

Componente que aplica reglas para permitir o bloquear tráfico de red. Complementa el cifrado Wi-Fi, pero cumple una función diferente.

Privacidad

VPN

Conexión cifrada entre un dispositivo y un servicio VPN. Puede proteger parte del tráfico frente a la red local, pero no garantiza que todos los sitios o servicios sean seguros.

Antecedentes · Redes móviles

Antecedentes de 5G

5G continúa la evolución de las redes móviles. La UIT define el marco IMT-2020 y 3GPP desarrolla las especificaciones del sistema 5G; la primera fase de 5G se especificó en Release 15. La disponibilidad de cada función depende de las versiones y despliegues del operador.

Organización · Estándares móviles

3GPP

Proyecto de colaboración entre organizaciones de normalización que desarrolla especificaciones técnicas para sistemas móviles, incluido 5G. No es un operador ni una autoridad reguladora; las asignaciones de espectro corresponden a organismos y gobiernos de cada región.

Marco · UIT-R

IMT-2020

Marco de la UIT para los sistemas móviles de quinta generación y nombre de sus requisitos y especificaciones de interfaces radio terrestres. 5G es el término de uso común; las tecnologías concretas se especifican mediante estándares como los de 3GPP.

Dispositivo · Red móvil

UE (equipo de usuario)

Equipo que utiliza una persona o servicio para conectarse a la red móvil, como un teléfono, módem o dispositivo IoT. En 5G, el UE intercambia señalización y datos con la red de acceso y puede identificarse y autenticarse mediante credenciales de abonado.

Servicios · Casos de uso

eMBB, URLLC y mMTC

Familias de escenarios de uso: banda ancha móvil mejorada (eMBB), comunicaciones de baja latencia y alta fiabilidad (URLLC), y comunicaciones masivas tipo máquina (mMTC). Son objetivos para distintos casos de uso, no garantías de que toda red 5G ofrezca siempre esas prestaciones.

Evolución · 3GPP

5G-Advanced

Nombre que 3GPP utiliza para la evolución de 5G a partir de Release 18. Incorpora mejoras y nuevas funciones al sistema; su inclusión en una especificación no significa que estén activadas por todos los operadores o dispositivos.

Arquitectura · Núcleo 5G

Arquitectura basada en servicios (SBA)

Modelo del 5GC en el que las funciones de red ofrecen servicios a otras funciones autorizadas mediante interfaces comunes. Facilita una arquitectura modular; no significa que las funciones estén expuestas sin controles de autorización.

Núcleo · Funciones de red

UDM, AUSF y PCF

Funciones del núcleo 5G: UDM gestiona datos de suscripción; AUSF participa en la autenticación; PCF proporciona reglas de política. Interactúan con otras funciones del 5GC según los procedimientos y la arquitectura de la red.

Sesión · Datos móviles

Sesión PDU

Conexión lógica que permite al UE intercambiar datos con una red de datos mediante el 5GC. Sus parámetros y encaminamiento se gestionan durante el establecimiento y la modificación de la sesión; no equivalen a una llamada de voz.

Seguridad · Identidad

5G-AKA y SUCI

5G-AKA es uno de los mecanismos de autenticación del sistema 5G. SUCI es una forma protegida de representar la identidad permanente del abonado al transmitirla por radio. La protección depende de la configuración de la red y de las credenciales del abonado.

Radio · Recursos

Numerología NR

5G NR permite configurar el espaciado entre subportadoras y la duración de los símbolos en función de la banda y el despliegue. Esta flexibilidad adapta la interfaz radio a distintos escenarios; no determina por sí sola la cobertura ni la velocidad.

Estándar · Radio móvil

5G NR

5G New Radio es la interfaz de radio definida por 3GPP para redes 5G. Usa recursos de tiempo y frecuencia configurables, y admite distintas bandas, anchos de canal y esquemas de transmisión.

Arquitectura

5G NSA y SA

NSA (Non-Standalone) combina radio 5G con una infraestructura LTE existente, normalmente con núcleo 4G. SA (Standalone) conecta la radio 5G a un núcleo 5G y habilita funciones nativas como segmentación de red; la disponibilidad depende del operador.

Radio · Espectro

Espectro radioeléctrico

Conjunto de frecuencias de ondas electromagnéticas que pueden utilizarse para comunicaciones inalámbricas. Los gobiernos asignan bandas y licencias; las reglas de uso, potencia y canales varían por país para coordinar servicios y reducir interferencias.

Radio · Bandas

Bandas 5G: baja, media y milimétrica

Las frecuencias bajas suelen cubrir áreas amplias; las medias equilibran cobertura y capacidad; las bandas milimétricas ofrecen canales anchos, pero su alcance y penetración en edificios son menores. Las bandas concretas autorizadas dependen del país y del operador.

Radio · Capacidad

Ancho de banda de canal

Rango de frecuencias que ocupa un canal, medido en hertz. En 5G NR puede configurarse con distintos anchos según la banda y el equipo. Un canal más ancho puede transportar más datos, pero no equivale por sí solo a mayor velocidad: también importan la señal, la carga y la asignación de recursos.

Modulación

QPSK y QAM

Esquemas que representan bits mediante símbolos de radio. 5G NR puede usar QPSK y QAM de orden superior, como 16-QAM, 64-QAM o 256-QAM, cuando las condiciones lo permiten. Los órdenes mayores transportan más bits por símbolo, pero requieren una señal de mejor calidad.

Multiplexación · Radio

OFDM y OFDMA

OFDM divide la transmisión en subportadoras ortogonales que transportan datos en paralelo. 5G NR usa formas de onda basadas en OFDM; al asignar grupos de subportadoras a distintos usuarios en tiempo y frecuencia se comparte eficientemente el canal, en un esquema de acceso múltiple por división de frecuencia ortogonal.

Duplexación

TDD y FDD

Métodos para separar la transmisión y recepción. FDD usa frecuencias distintas para cada sentido; TDD comparte una frecuencia y alterna intervalos de tiempo. La banda asignada y la configuración de la red determinan cuál se emplea.

Antenas · MIMO

Massive MIMO y beamforming

Massive MIMO emplea numerosas antenas para atender varios flujos y usuarios. El beamforming ajusta la fase y amplitud de las señales para concentrar energía en ciertas direcciones, mejorando potencialmente cobertura y capacidad; no elimina obstáculos ni garantiza una velocidad concreta.

Acceso radioeléctrico

gNB

Nombre de la estación base 5G NR que proporciona cobertura de radio y conecta los dispositivos con la red de acceso. Puede incluir radios y antenas en el sitio y funciones de procesamiento distribuidas o centralizadas.

Infraestructura

NG-RAN

Red de acceso radioeléctrico de nueva generación de 5G. Incluye gNB conectados entre sí y al núcleo 5G mediante interfaces normalizadas; sus funciones pueden distribuirse entre unidades centralizadas y distribuidas.

Núcleo de red

5GC

5G Core es el núcleo de paquetes de una red 5G. Gestiona registro y movilidad, sesiones de datos, políticas y conexión con redes externas mediante funciones modulares comunicadas por interfaces definidas por 3GPP.

Núcleo · Control

AMF y SMF

Funciones del núcleo 5G: AMF gestiona acceso y movilidad del equipo; SMF administra sesiones de conectividad y configura el encaminamiento de datos junto con otras funciones del núcleo. Son funciones de red, no protocolos de radio.

Núcleo · Plano de usuario

UPF

La User Plane Function procesa y reenvía el tráfico de usuario entre la red de acceso y redes de datos. Puede ubicarse cerca de los usuarios para reducir el recorrido de ciertos datos, según la arquitectura del operador.

Protocolos · Interfaz de radio

Protocolos de acceso 5G

En la interfaz NR, RRC controla la conexión de radio; PDCP, RLC y MAC procesan y organizan datos en capas; PHY transmite símbolos por radio. NAS intercambia señalización entre el dispositivo y el núcleo para registro y movilidad. Cada protocolo cumple una función distinta.

Transporte · Infraestructura

Fronthaul y backhaul

Enlaces de transporte que conectan componentes de la red móvil. Fronthaul puede enlazar radios con unidades de procesamiento distribuidas; backhaul lleva el tráfico desde estaciones base hacia el núcleo y otras redes. Pueden usar fibra, microondas u otros medios.

Arquitectura · Servicios

Network slicing

Función de 5G que permite configurar segmentos lógicos de una infraestructura compartida con políticas y recursos distintos para ciertos servicios. No crea redes físicas independientes ni garantiza por sí sola aislamiento absoluto o calidad determinada.

Los conceptos de 5G se contrastaron con fuentes oficiales de 3GPP y la UIT. Consulta las especificaciones para el detalle técnico y las capacidades desplegadas por cada operador.
